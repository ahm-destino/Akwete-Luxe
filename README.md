# Akwete Luxe — Handwoven Textile Atelier

Direct marketplace connecting buyers worldwide with master female Akwete weavers in Abia State, Nigeria.

## Tech Stack

- **React 19** + **TypeScript**
- **Vite** (build tool)
- **Tailwind CSS v4**
- **Lucide React** (icons)
- **Motion** (animations)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Build for Production

```bash
npm run build
```

Output will be in the `dist/` folder.

## Deploy to Vercel

This project is ready for Vercel. Just connect your repository and Vercel will auto-detect the Vite framework.

- **Framework Preset:** Vite
- **Build Command:** `npm run build`
- **Output Directory:** `dist`
